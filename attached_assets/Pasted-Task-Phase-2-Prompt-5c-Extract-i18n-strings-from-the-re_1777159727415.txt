Step 3: AI chat — UI chrome only, NOT system prompts
The DuitPlan AI page has both UI chrome (translatable) and AI system instructions (NOT translatable in this prompt).
What to extract and translate:

Page title ("DuitPlan AI") and subtitle/tagline
Input placeholder ("Ask me about your finances..." or similar)
Send button label
Loading states ("Thinking...", "Generating response...")
Empty state ("Ask me anything about your money", suggested prompt chips if any)
Error states ("Failed to send", "Connection lost", retry buttons)
Conversation actions (Clear chat, Copy, Regenerate)
Header / branding text on the chat interface

What to NOT touch:

The system prompt sent to the LLM (the instructions defining what DuitPlan AI is and how it behaves) — this stays hardcoded in English in the backend. The AI's responses to user questions will naturally come back in whatever language the user typed in, and the LLM handles that automatically. We don't need to translate the system prompt to make this work.
User-typed messages or AI responses — these are conversational content, not UI strings.
Any backend API logic.

Note on regional context for AI: The AI's system prompt currently references Brunei-specific context (BIBD, BND, etc.). Region-aware AI prompting is logged in REGION_CONTENT_BACKLOG.md for Phase 3 — do NOT address it here.
