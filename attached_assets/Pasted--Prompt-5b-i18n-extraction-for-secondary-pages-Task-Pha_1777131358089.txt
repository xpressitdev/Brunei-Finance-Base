Step 1: Read existing locale files first
Before writing any new translations, open src/i18n/locales/ms.json and id.json and study the existing terminology. The user has refined these files with specific term choices that MUST be respected for consistency. In particular:

Indonesian (id.json) uses "Rekening" for bank accounts, not "Akun". Maintain this convention everywhere.
Both files use "Tanpa kategori" for "Uncategorized", not "Tidak dikategorikan". Use "Tanpa kategori" for all new translations.
Indonesian uses "Tanggal" for date; Malay uses "Tarikh". Don't swap these.
Indonesian uses "Pengeluaran/Pemasukan"; Malay uses "Perbelanjaan/Pendapatan". Don't mix.
"Liabilities" was translated as "Tanggungan" in Malay and "Kewajiban" in Indonesian. If similar concepts arise on Net Worth or Debts pages, use the same terms.

If you encounter a term not yet in the locale files, pick the most natural translation and apply it consistently across both files.
