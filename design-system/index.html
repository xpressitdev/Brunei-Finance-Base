DuitPlan Design System

A calm teal/green token system built for personal finance across Brunei, Malaysia, and Indonesia. Covers colors, typography, spacing, components, and brand assets.

Stack: React 18 + Tailwind via CDN Font: Inter (400–700) Tokens: HSL CSS vars Components: 10+ Locales: EN / MS / ID

📦 Handoff — Ready to implement

This bundle includes a production-ready drop-in for the Budgets page: handoff/budgets.tsx.
It adds an Allocate tab (drag-and-drop envelope budgeting) while keeping your existing Forecast Plan, Actual vs Plan, and Annual Report tabs intact.
No new dependencies. No backend changes. Replace artifacts/duitplan/src/pages/budgets.tsx and deploy.
