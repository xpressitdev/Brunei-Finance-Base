# DuitPlan Marketing Site UI Kit

A hi-fi recreation of the marketing landing page at `duitplan.com`. Single static HTML file — no build, no JS framework. Tailwind via CDN for speed.

**Sections (in order)**
- **Header** — sticky, blurred white. Brand lockup left, primary nav, sign-in + Start Free.
- **Hero** — left: headline ("Understand your gaji. Plan every duit."), eyebrow region pill, dual CTA. Right: a layered card mockup showing the dashboard "Remaining" tile and three transaction rows using the brand illustrations.
- **Features** — three cards on tinted background, each anchored by one of the flow illustrations (payslip / bank / vault).
- **How it works** — three numbered steps in primary tiles.
- **CTA band** — full-bleed `bg-primary` with white text.
- **Footer** — minimal copyright, terms.

Calm, no gradients, generous whitespace. Built to demonstrate the marketing side of the system: where DuitPlan introduces itself before someone signs in.
